# BW1000 硬件介绍与优化参考

> 节点: **bw22**, 8 × BW1000 (BW200_LC / UBB BW1000_LC), OAM 形态
> 信息来源: `hy-smi`、`lspci`

## 1. 本机实测摘要

| 项目 | BW1000 本机信息 |
|---|---|
| 卡数量 | 8 张 |
| 产品名 | BW1000 (Card Series: BW200_LC, UBB BW1000_LC) |
| 厂商 | C-3000 IC Design Co., Ltd. |
| PCI 设备 | DID=6320, SSID=6311 |
| 运行时架构 | gfx936:sramecc+:xnack- |
| CU 数量 | 80 CU / 卡 |
| 显存 | 65520 MiB / 卡, 约 64.0 GiB |
| ECC | VRAM ECC ON |
| 最大板卡功耗 | 800 W |
| sclk | **1500 MHz** (level 10) |
| 拓扑 | 8 卡全互联, 链路类型 HSW, OAM 形态 |
| PCIe | HYGON HCU-3G [1d94:6430] |
| 驱动 | hy-smi 可用 |

## 2. PCI 与 OAM 映射

| HCU | PCI Bus | OAM ID |
|---:|---|---:|
| 0 | `0000:9f:00.0` | 1 |
| 1 | `0000:56:00.0` | 0 |
| 2 | `0000:5d:00.0` | 4 |
| 3 | `0000:05:00.0` | 5 |
| 4 | `0000:e8:00.0` | 3 |
| 5 | `0000:c1:00.0` | 2 |
| 6 | `0000:ca:00.0` | 7 |
| 7 | `0000:b1:00.0` | 6 |

> OAM 8 卡, 全互联可达。

## 3. 与 BW1000/BW1100 对比

| 项目 | BW200_LC | BW1000_H | BW1100 |
|---|---:|---:|---:|
| CU 数量 | 80 | 88/80 | 64 |
| 显存 | 64 GB | 64 GB | 144 GB |
| sclk | **1500 MHz** | — | 1350 MHz |
| 功耗 | 800 W | 700 W | 800 W |
| 形态 | OAM | OAM | OAM |
| DID | 6320 | 6320 | 6430 |
| 架构 | gfx938 | gfx926 | gfx938 |

> **关键**: BW200_LC sclk 1500 MHz 是已测机型中最高的, 单卡算力潜力最大。

## 4. HIP 编译与算子优化

- 编译 target: `--offload-arch=gfx936`
- 多架构兼容: `--offload-arch=gfx936;gfx938`
- Occupancy: 按 80 CU 估算
- 功耗 800W: 长时间高负载需注意温度墙
