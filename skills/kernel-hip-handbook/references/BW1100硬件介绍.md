# BW1100 硬件介绍与优化参考

> 节点: **nmz21**, 8 × BW1100, OAM 形态
> 信息来源: `hy-smi`、`lspci`

## 1. 本机实测摘要

| 项目 | BW1100 本机信息 |
|---|---|
| 卡数量 | 8 张 |
| 产品名 | BW1100 |
| 厂商 | C-3000 IC Design Co., Ltd. |
| PCI 设备 | DID=6430, SSID=6430, HYGON HCU-3G [1d94:6430] |
| 运行时架构 | gfx938（与 BW1101 同族, SSID=6430 vs BW1101 SSID=6433） |
| CU 数量 | 64 CU / 卡 |
| 显存 | 147440 MiB / 卡, 约 144.0 GiB |
| ECC | VRAM ECC ON |
| 最大板卡功耗 | 800 W |
| sclk | 1350 MHz (level 8) |
| 拓扑 | 8 卡全互联, 链路类型 HSW, OAM 形态 |
| 驱动 | hy-smi 可用 |

## 3. 与 BW1101/BW10 对比

| 项目 | BW1100 | BW1101 | BW10 |
|---|---:|---:|---:|
| CU 数量 | 64 | 64 | 48 |
| 显存 | **144 GB** | 144 GB | 31 GB |
| sclk | 1350 MHz | 1350 MHz | 760 MHz |
| 功耗 | 800 W | 800 W | 150 W |
| 形态 | OAM | OAM | PCIe |
| DID | 6430 | 6430 | — |
| SSID | 6430 | 6433 | — |
| 架构 | gfx938 | gfx938 | gfx936 |

> **注意**: BW1100 与 BW1101 同属 BW1100 系列, 仅 SSID 不同 (6430 vs 6433)。
> 144 GB 大显存: 可支撑大 batch 训练、大模型推理, 显存是 BW10 的 4.6×, BW150 的 2.25×。

## 4. HIP 编译与算子优化

- 编译 target: `--offload-arch=gfx938` (与 BW1101 一致)
- 多架构兼容: `--offload-arch=gfx926;gfx936;gfx938`
- Occupancy: 按 64 CU 估算
- 144 GB 显存策略: 可关闭 checkpoint, 增大 batch size 换吞吐
