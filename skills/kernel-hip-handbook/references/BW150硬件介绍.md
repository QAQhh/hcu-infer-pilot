# BW150 硬件介绍与优化参考

> 节点: **bw150-2**, 8 × BW150 PCIe 卡
> 信息来源: `hy-smi`、`lspci`、`/usr/local/hyhal/bin/update_ids`

## 1. 本机实测摘要

| 项目 | BW150 本机信息 |
|---|---|
| 卡数量 | 8 张 |
| 产品名 | BW150 |
| 厂商 | C-3000 IC Design Co., Ltd. |
| PCI 设备 | DID=6320, SSID=6320 |
| 运行时架构 | gfx936:sramecc+:xnack- |
| CU 数量 | 80 CU / 卡 (推测, hy-smi 报告 80) |
| 显存 | 65520 MiB / 卡, 约 64.0 GiB |
| ECC | VRAM ECC ON |
| 最大板卡功耗 | 待确认 |
| sclk | 1400 MHz (level 8) |
| 拓扑 | 8 卡全互联可达, 任意 HCU 间可达 |
| PCIe | 多 PCIe 插槽 |
| 驱动 | hy-smi 可用 |

## 2. PCI 与槽位拓扑

| HCU | PCI Bus | Socket ID |
|---:|---:|---:|
| 0 | `0000:07:00.0` | 0 |
| 1 | `0000:0a:00.0` | 1 |
| 2 | `0000:0f:00.0` | 2 |
| 3 | `0000:16:00.0` | 3 |
| 4 | `0000:1d:00.0` | 0 |
| 5 | `0000:20:00.0` | 1 |
| 6 | `0000:25:00.0` | 2 |
| 7 | `0000:2c:00.0` | 3 |

> **注意**: BW150 为 PCIe 卡形态, 8 卡分布在 4 个 Socket, 每 Socket 2 张卡。

## 3. 与 BW10/BW1000 对比

| 项目 | BW150 | BW10 | BW1000 |
|---|---:|---:|---:|
| CU 数量 | 80 | 48 | 80 |
| 显存 | 64 GB | 31 GB | 64 GB |
| sclk | 1400 MHz | 760 MHz | 1500 MHz |
| 形态 | PCIe | PCIe | OAM |
| 架构 | gfx936 | gfx936 | gfx936 |

> BW150/BW10/BW1000 全部为 gfx936 架构, 编译 target 统一为 `--offload-arch=gfx936`。

## 4. HIP 编译与算子优化

- 编译 target: `--offload-arch=gfx936`
- 多架构兼容: `--offload-arch=gfx936;gfx938`
- Occupancy: 按 80 CU 估算
